# Release v0.1.0

## Initial Release - MDV Windows Port

This is the first release of MDV Windows, a Windows port of the markdown viewer (mdv).

### Features Implemented
- **Core WPF/MVVM Architecture**: Complete foundation with proper separation of concerns
- **Markdown Rendering**: Full markdown file rendering and display capabilities
- **File Navigation**: Browse and navigate markdown files
- **Search Functionality**: Search within markdown content
- **Theme Support**: Multiple theme options for viewing preferences
- **Live Reload**: Auto-refresh when markdown files are modified
- **Persistence**: Remember user preferences and last viewed files
- **Modern UI**: Professional Windows Presentation Foundation interface

### What's New
- Initial implementation of the complete mdv-windows feature set
- End-to-end functionality from file selection to rendering
- Integrated search and navigation features
- Theme customization and persistence

### Release Notes
- Project structure and boilerplate setup
- Full WPF/MVVM implementation with core features
- Ready for alpha testing and user feedback

### Getting Started
1. Clone the repository
2. Open the solution in Visual Studio
3. Build the project
4. Run mdv-windows.exe

### Known Limitations
As an alpha release, there may be edge cases and features that require refinement based on user feedback.
